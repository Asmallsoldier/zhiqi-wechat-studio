## 生成公开源码包

先将审核过的源码加入Git，再执行：

```sh
python scripts/check-docs.py
python scripts/release.py --check
python scripts/release.py
```

脚本只读取Git跟踪且位于白名单内的公开文件；不读取忽略的私有运行目录。ZIP附带各源文件SHA256清单，不包含`.git`、真实`.env`、数据库、备份、密钥、node_modules或生成日志。导出前仍需人工审查拟公开代码、商标与第三方来源权利，扫描不是法律或敏感信息完备性证明。
