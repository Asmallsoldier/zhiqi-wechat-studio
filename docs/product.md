# 智启图文 · WeChat Studio 产品说明

版本：0.3.0 开源准备版 · 更新：2026年10月29日

## 产品定位

智启图文是一款可独立部署的公众号内容运营平台，面向需要持续输出科技资讯、行业观察和数码购买指南的创作者与小型内容团队。它把资料整理、选品研究、AI写作、配图、公众号投递和结果核对连接起来，让每篇内容有依据、每次发表有进度。

产品以公众号为核心，采用自己的登录、权限、账号和数据存储。可以安装在自己的服务器上，通过独立域名或端口使用。开源代码不要求同时运行原来的综合平台，也不附带付费数据源或模型服务。

## 核心价值

**内容从资料出发。** 运营者先选择公开资料或导入商品，再组织文章；系统保留时间和原链接，便于核验事实。AI用于解释变化、适用人群与风险，减少机械拼接消息来源的表达。

**研究先于推荐。** 数码选品比较相同型号、配置、成色的近期样本，计算含运费挂牌价中位数，标出需要核验的候选；对样本不足和风险未确认的商品停止推荐，不虚构成交价或亲测结果。

**图文一起交付。** 文章配有封面和两张正文资料图解，分别帮助读者理解比较依据与风险。图解由平台生成并标明性质，不冒充商品实拍。

**发表有最终结果。** 运营者选择草稿或正式发表，任务逐步显示账号检查、生成、校验、配图、提交和结果确认。微信异步处理中不显示已发表，最终成功后提供正式文章链接。

## 两条主要流程

### 科技与行业资讯

在资料雷达刷新来源并选择近期资料 → 提出选题 → AI独立组织文章或生成证据摘要 → 查看正文与引用依据 → 选择公众号和交付方式 → 自动检查内容、准备配图并投递 → 查看草稿编号或正式链接。

来源目录包含36个候选入口，逐源显示当前可用状态。目录数量不代表36个站点始终可抓取；文章应区分发布方声明、独立证实和编辑推断。

### 闲鱼数码选品

使用自己获授权的数据接口，或导入合法获得的真实商品资料 → 比较近期同配置挂牌样本 → 找出有价格优势且无已识别风险的候选 → 生成购买核验分析文章 → 自动校验金额、引用、时效和承诺用语 → 配图并投递公众号 → 查询最终结果。

当前公开页可能受登录与风控限制，平台遇到限制会停止，不绕过验证码或登录。真实数据入口需要运营者配置；该功能不自动下单，也不保证商品质量。

## 功能范围

| 模块 | 当前独立版能力 |
| --- | --- |
| 工作空间 | 独立登录、个人改密、本地角色、按用户隔离资料 |
| 账号管理 | 添加公众号、加密凭据、连接检查、账号发表授权 |
| 资料研究 | 来源健康、资讯缓存、商品导入、确定性比较和风险提示 |

| 部署运维 | Docker Compose、独立数据库、私有配置、备份与源码发布扫描 |

## 角色与协作

super_admin 拥有全部权限；wechat_operator 可以操作自己的公众号资料与发表任务；readonly_operator 只能查看自己的资料。用户由部署管理员通过本地CLI创建、改角色、重置密码或停用，不开放匿名注册。当前不支持多人共享同一个公众号的团队授权。

凭据加密保存在自己的部署中，页面不返回AppSecret；密码、角色或凭据发生变化会使旧任务授权失效。发表还需要部署开关、账号开关与本次任务授权共同满足。

## 技术架构与扩展

前端采用 Vue 3、TypeScript、Vite、TDesign和Element Plus，后端采用 Python 3.12、FastAPI、SQLite WAL。Nginx统一入口；Pillow生成资料图解；模型使用兼容Chat Completions的接口。默认部署为前端和API两个容器，不强制引入消息队列或外部数据库。

研究流程和微信执行器分别保存状态、内容哈希、写入意图及回执。相同请求幂等处理；未知写入结果停止重发，查询失败可重试。当前面向单进程、单副本部署；后续可按实际规模扩展调度、团队协作与存储。

## 开源与使用条件

项目自有源码与文档采用Apache-2.0，第三方组件保留各自许可。公开源码包不包含生产配置、账号密钥、用户数据库、采集内容、原项目历史或模型权重。模型、数据提供方、服务器和微信公众号接口的成本与权限由部署者自行准备。

AI辅助表达不等于自动获得内容权利或事实准确保证。运营者仍需核验资料、适用条件、转载许可和公众号发布规则。正式发表不同于主动群发给粉丝，本版不包含主动群发。

## 当前状态与后续方向

0.3.0已实现独立身份、账号、资料、选品、文章和按次图文投递，准备公开源码。测试以隔离数据库、模拟模型/微信回执为主；真实闲鱼数据到正式微信链接的完整验收仍需数据接口与具备权限的公众号配合。

原综合平台的通用工作流、运营日历和定时计划尚未全部移植到独立版。下一阶段优先完成真实链路验收、团队账号授权、定时选题计划及来源质量评估，不以新增数据源数量代替内容质量。
