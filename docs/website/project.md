## 详情页正文

### 把内容运营连成一条可追踪的流程

运营公众号需要的不只是生成一篇文字。资料是否可靠、数字是否有依据、文章是否有配图、微信是否真正发表，都影响最终交付。

智启图文把这些工作放到一个独立空间中：从公开资讯或商品资料开始，形成研究依据，由AI组织文章和资料图解，再根据运营者选择投递草稿或提交正式发表。每次任务保留阶段与回执，微信最终确认成功后展示正式文章链接。

### 从资讯解读到数码购买核验

资料雷达提供科技与行业来源目录，运营者可以选择近期资料组织选题。数码选品模块比较同配置、同成色的近期挂牌样本，标出值得进一步核验的候选，并保留原链接和风险边界。它不把挂牌价说成成交价，也不虚构实测经历。

### 自己部署，掌握账号和数据

平台具有独立登录、角色权限、公众号账号管理和数据库，支持Docker部署。公众号凭据加密保存，模型和数据接口由部署者选择。前端Vue 3，后端FastAPI，轻量存储SQLite，适合个人创作者与小型内容团队自建内容工作台。

### 公开源码，逐步完善

项目按Apache-2.0准备开源，源码包剔除生产密钥、数据库和运行记录。当前独立版支持资料、研究、文章和按次投递；真实闲鱼数据入口及微信正式发表需要运营者具备数据许可和平台权限，完整真实链路仍待验收。通用定时运营计划和团队账号共享列入后续迭代。
