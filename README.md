# 智启图文 · Zhiqi WeChat Studio

把公开资料和数码选品研究，变成有依据、有配图、可追踪发表结果的公众号文章。

独立部署的内容运营平台，采用 Vue 3、FastAPI 和 SQLite，默认使用自己的登录、用户角色、账号凭据及微信执行器。无需启动原主平台、PostgreSQL、RabbitMQ 或 Redis。项目源码采用 [Apache-2.0](LICENSE)，当前版本 **0.3.1**。

[公开仓库](https://github.com/Asmallsoldier/zhiqi-wechat-studio) · [官方工作台](https://aipip.cn/wechat/)

## 能做什么

- **资料雷达**：36 个候选资讯/技术来源，逐源保存可用状态；从缓存资料选择选题并生成文章。
- **数码选品研究**：导入结构化商品，或接入已获授权的数据接口；按型号、配置、成色比较含运费挂牌价、样本和风险。
- **文章与配图**：接入兼容 Chat Completions 的模型，独立组织中文文章；保留来源和模型回执，生成封面及两张正文资料图解。
- **公众号投递**：文章校验 → 上传配图 → 创建草稿 → 可选正式发表 → 查询微信最终结果 → 保存正式链接。提交成功仅表示处理中。
- **可恢复任务**：持久化步骤、内容快照、提交意图、执行锁与回执；结果不明的写入不会自动重复，服务重启后可继续原任务。
- **自己的工作空间**：本地用户与三类角色，按用户隔离资料、账号和文章；微信凭据加密保存，页面不返回密钥。

## 五分钟启动

需要 Docker Engine 和 Compose 插件，或 Docker Desktop；首次构建需要联网下载依赖。

```sh
cp .env.example .env
docker compose up -d --build
docker compose exec api python -m app.manage create-user --username owner --role super_admin
```

按提示输入自己的强密码，然后访问 **http://localhost:3103**。没有默认账号或默认密码。首次启动不调用模型，不采集商品，不向微信上传或发表；可先浏览界面、导入资料与生成证据分析稿。

在“公众号账号”添加自己的公众号并配置 AppID、AppSecret。检查微信连接仅获取 Token，不能证明拥有草稿/发表接口权限。要执行草稿或正式发表，按[部署指南](docs/deployment.md)分别开放开关并确认账号授权。

## 使用边界

- 闲鱼并未提供本项目可直接使用的匿名搜索能力。公开页遇到登录、验证码或限流会停止；**不会绕过验证**。真实选品需要合法获得的结构化资料或自行配置授权提供方。仓库不附带商品库、Cookie、供应商密钥或真实账号。
- 比较的是有限样本的挂牌价，不是市场成交价；“值得核验”不等于购买保证。AI 重组表达不保证法律意义上的原创，运营者仍须核验事实和内容权利。
- 微信需要账号具备对应权限、出口 IP 白名单、有效凭据。正式发表不同于主动群发给粉丝。本版未完成真实闲鱼数据到微信正式链接的端到端验收；测试使用明确标识的模拟数据与微信回执。
- 独立版包含资料、选品、文章、账号、按次投递任务。原平台的通用工作流、日历与定时运营计划尚未全部移植；`shared` 仅为已有部署的兼容入口，不是开源版的运行依赖。
